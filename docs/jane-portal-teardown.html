Jane patient portal: how the account page and booking flow are built

A passive teardown of a live, signed-in Jane App patient portal, captured with REA over Chrome DevTools in Microsoft Edge 155. It is a reference for designing the ClinicFlow patient experience.

Summary

What the portal is, in five lines.

How tab switching works

Read from the page's inline account script. This is observed source code, not a guess.

State in three places

  • The URL hash, e.g. #history, is the main source.
  • An account_tab cookie that lasts 10 minutes restores the last tab after a reload.
  • ?active_tab= is turned into a hash so deep links survive the sign-in redirect.

Edge cases handled

  • #wait_list is never restored. The page falls back to Upcoming.
  • At 480px wide or less, the remembered tab is not restored.
  • At 768px wide or less, opening Messages auto-scrolls to it.
  • Edit-relationship and edit-user hashes are mapped back to a valid tab.
// condensed from the page's inline script
$('#account-nav').on('click', 'a[data-toggle="tab"]', e => {
  e.preventDefault();
  $('.account-container').fadeOut(400);
  $(tab).delay(401).fadeIn(400);
  Cookies.set('account_tab', tab, { expires: in10Minutes });
  window.location.hash = tab;
});

Booking flow

The sequence recorded in the browser. Steps 1–3 happen inside the booking app without page loads.

  1. /#/registered-psychotherapist

    Choose a discipline and see its practitioners.

  2. /#/staff_member/:id

    Open one practitioner's page.

  3. /#/staff_member/:id/treatment/:id

    Choose a treatment and see open time slots.

  4. /appointments/confirm → /appointments/finalize

    Picking a slot sends the browser here, and the server creates the booking. This is the commit point.

  5. /appointments/:hex_id

    Confirmation page. The header changes to "You have 1 upcoming appointment."

Design consequence. Jane puts the commit before the "reason for visit" and reminder questions. A patient who is just exploring can book by accident. That happened during this capture, and the appointment was then cancelled. Jane's 48-hour cancellation-fee policy makes this costly.

Tracking and storage

Storage key names only; REA never reads the stored values.

Analytics hooks

  • mountMyAccountPageViewedTracking
  • mountAccountTabTracking
  • mountIntakeFormTracking('my_account')
  • mountSubscribeToCalendarTracking
  • mountAddWaitlistRequestTracking
  • Book buttons carry data-track-book-appointment and data-cta-location

Events go to RudderStack on a Jane-run data plane in a Canadian region, alongside Google tag.

Consent and storage

  • Google Consent Mode starts with analytics and ad storage denied.
  • Enzuzo handles the cookie banner and preferences.
  • localStorage: cookie_consent, csrf-token, _gcl_ls, RudderStack queue keys.
  • sessionStorage: browser_tab_id, which tells separate tabs apart.
